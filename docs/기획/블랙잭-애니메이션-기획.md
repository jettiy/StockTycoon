# 블랙잭 미니게임 기획서

## 1. 현재 구현

### NPCManager 블랙잭 API (scripts/autoload/NPCManager.gd)
- `bj_deal_user_cards()` — 유저 초기 2장 드로우, {cards: [{card, val}], total: int}
- `bj_user_hit(current_total)` — 유저 Hit 1장 추가, {card, val, total, busted}
- `bj_play_dealer()` — 딜러 자동 플레이 (16 이하 Hit), {cards: [{card, val}], total, busted}
- `bj_settle(user_total, dealer_total, bet)` — 결과 정산, {won, tie, payout}
- 유저가 Hit/Stand를 선택하는 인터랙티브 방식

### MainGame._show_blackjack_game() (scripts/MainGame.gd)
- CanvasLayer + 오버레이 패널로 블랙잭 UI 구성
- 베팅 → 유저 초기 2장 애니메이션 → **Hit/Stand 버튼 표시** → 유저 선택
- 딜러 자동 플레이 (face_down → flip 애니메이션) → 정산 → 결과 팝업
- "한 장 더"(Hit, 초록) / "멈추기"(Stand, 빨강) 버튼

### 흐름
1. **베팅 단계**: "도전!" 버튼으로 베팅금 차감
2. **플레이어 턴**: 유저 카드 2장 → 합계 표시 → Hit/Stand 선택
   - Hit: 1장 추가, busted(22+)면 즉시 패배
   - Stand: 딜러 턴으로 전환
   - 블랙잭(초기 2장으로 21): 자동 Stand
3. **딜러 턴**: 딜러 카드 face_down → flip → 16 이하면 추가 Hit → 합계 표시
4. **결과**: 승리/패배/무승부 팝업 + 금액 표시

## 2. 밸런스

### 배당
| 조건 | 배당 |
|------|------|
| 승리 (유저 > 딜러) | 1.5배 |
| 블랙잭 승리 (유저 = 21) | 2.0배 |
| 무승부 | 베팅금 환불 |
| 패배 | 0 (베팅금 소실) |
| 유저 버스트 | 0 (베팅금 소실, 딜러 카드 미공개) |
| 둘 다 버스트 | 베팅금 환불 (무승부) |

### 딜러 룰
- 16 이하: 반드시 Hit
- 17 이상: Stand
- 버스트(22+): 패배 처리

### 기대값
유저의 의사결정이 개입되므로 정확한 기대값은 유저 플레이에 따라 달라짐.
최적 전략 시 약 -2~3% (카지노 기준).

## 3. 애니메이션 시퀀스

### 전체 흐름 (인터랙티브 — 유저 선택 대기 구간 포함)
```
0.0s  패널 등장 (UIAnim.pop_in)
0.0s  "골드버그 - 블랙잭" 타이틀 표시
─── 베팅 단계 (유저가 "도전!" 클릭) ───
0.3s  유저 카드 1장 슬라이드 인 (UIAnim.slide_in_from_left)
0.55s 유저 카드 2장 슬라이드 인
0.75s 유저 합계 표시 (flash_up)
─── 플레이어 턴 (유저 선택 대기) ───
      "한 장 더" / "멈추기" 버튼 표시
      [Hit 클릭]마다: 카드 슬라이드 인 + 합계 갱신
      [busted] flash_down + shake → 즉시 결과
      [Stand 또는 21] → 딜러 턴
─── 딜러 턴 ───
0.3s  딜러 카드 1장 face_down 슬라이드 인
0.55s 딜러 카드 2장 face_down 슬라이드 인
1.0s  딜러 카드 전부 flip (modulate.a 0→1)
1.3s  딜러 합계 표시
      [딜러 3장+] 추가 flip + 합계 갱신
─── 결과 ───
0.5s  결과 팝업 (승리/패배/무승부)
1.0s  금액 팝업 표시 (+X원 / -X원)
      "닫기" 버튼으로 종료
```

### 재사용 UIAnim 메서드
- `pop_in(node)` — 패널 등장
- `slide_in_from_left(node, distance, duration)` — 카드 슬라이드
- `flash_up/flash_down(node)` — 합계/결과 하이라이트
- `fade_out(node)` — 패널 사라짐
- `shake(node)` — 버스트 시 진동

### 신규 필요 애니메이션
- **카드 뒤집기**: modulate.a → 0 → 텍스트/색상 변경 → modulate.a → 1 (0.3초)
- **카드 슬라이드 인 (좌측)**: position.x = -60 → 원위치 (0.25초, EASE_OUT)

### NPCManager 블랙잭 API
```gdscript
## 유저 초기 2장 드로우
func bj_deal_user_cards() -> Dictionary:
    var cards: Array = []
    var total: int = 0
    for i in 2:
        var card: int = _rng.randi_range(1, 13)
        var val: int = min(card, 10)
        cards.append({"card": card, "val": val})
        total += val
    return {"cards": cards, "total": total}

## 유저 Hit (1장 추가)
func bj_user_hit(current_total: int) -> Dictionary:
    var card: int = _rng.randi_range(1, 13)
    var val: int = min(card, 10)
    var new_total: int = current_total + val
    return {"card": card, "val": val, "total": new_total, "busted": new_total > 21}

## 딜러 자동 플레이 (16 이하면 Hit)
func bj_play_dealer() -> Dictionary:
    var cards: Array = []
    var total: int = 0
    for i in 2:
        var card: int = _rng.randi_range(1, 13)
        var val: int = min(card, 10)
        cards.append({"card": card, "val": val})
        total += val
    while total <= 16:
        var card: int = _rng.randi_range(1, 13)
        var val: int = min(card, 10)
        cards.append({"card": card, "val": val})
        total += val
    return {"cards": cards, "total": total, "busted": total > 21}

## 결과 정산
func bj_settle(user_total: int, dealer_total: int, bet: float) -> Dictionary:
    # 유저 busted → 무조건 패배 (딜러 카드 무관)
    # 정상 비교: 승리 1.5배, 블랙잭(21) 2배, 무승부 환불, 패배 0
    # 딜러 busted + 유저 정상 → 유저 승리 1.5배
    # 둘 다 busted → 무승부 (환불)
    return {"won": bool, "tie": bool, "payout": float}
```

### MainGame._show_blackjack_game() 구현 패턴
1. CanvasLayer(layer=95) + ColorRect 오버레이
2. CenterContainer + PanelContainer
3. VBoxContainer에 유저존/VS/딜러존 HBox 배치
4. 버튼 영역: HBoxContainer("BjBtnArea")에 도전!/한 장 더/멈추기
5. 각 카드는 Panel(60x84) + 내부 Label
6. _make_card_panel()은 기존 유지
7. GameClockManager.pause_for_event() / resume_from_event()

### MainGame 블랙잭 상태 변수
```gdscript
var _bj_layer: CanvasLayer = null
var _bj_npc_id: String = ""
var _bj_bet: float = 0.0
var _bj_settled: bool = false
var _bj_user_cards: Array = []      # [{"card": int, "val": int}, ...]
var _bj_user_total: int = 0
var _bj_phase: String = ""          # "bet", "player_turn", "dealer_turn", "result"
```

### 주요 흐름
1. `_on_bj_start()`: 베팅 차감 → bj_deal_user_cards() → 카드 애니메이션 → 21이면 자동 Stand, 아니면 Hit/Stand 표시
2. `_on_bj_hit()`: bj_user_hit() → 카드 애니메이션 → busted면 즉시 패배, 21이면 자동 Stand
3. `_on_bj_stand()`: 버튼 숨기기 → _resolve_bj()
4. `_resolve_bj()`: 유저 busted면 패배, 아니면 bj_play_dealer() → flip 애니메이션 → bj_settle() → _show_bj_result()
5. `_show_bj_result()`: 결과 팝업 + 금액 표시 + 기록
