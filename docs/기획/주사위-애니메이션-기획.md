# 주사위 미니게임 기획서 (알고리즘 K)

## 1. 게임 개요

주사위 2개를 굴려 합계가 높은 쪽이 승리합니다. 알고리즘 K와의 확률 승부.

### 대상 NPC
- id: `algo_k`, name: "알고리즘 K", role: "주사위 확률론자"
- game_type: `dice`
- avatar_color: `#00BCD4`

### 흐름
1. **베팅 단계**: 베팅금 설정 후 "대결!" 버튼으로 베팅 차감
2. **유저 굴림**: 주사위 2개 등장 → 숫자 빠르게 변경 애니메이션 → 확정, 합계 표시
3. **NPC 굴림**: 주사위 2개 등장 → 동일 애니메이션 → 확정, 합계 표시
4. **결과**: 합계 비교 → 승리/패배 팝업 + 금액 표시
   - 동점 시: 최대 3회 재굴림

## 2. 룰

### 배당

| 조건 | 배당 |
|------|------|
| 승리 (유저 합계 > NPC 합계) | 1.8배 |
| 패배 (유저 합계 < NPC 합계) | 0 (베팅금 소실) |
| 동점 (합계 동일) | 최대 3회 재굴림, 이후 패배 처리 |

### 주사위
- 유저: 주사위 2개 (각 1~6), 합계 범위 2~12
- NPC: 주사위 2개 (각 1~6), 합계 범위 2~12

### 동점 처리
1. 동점 발생 시 자동 재굴림 (유저→NPC 순서)
2. 최대 3회 재시도
3. 3회 재시도 후에도 동점이면 유저 패배 처리

### 기대값
- 승리 확률 약 57.9% (단순 확률), 배당 1.8배
- 기대값: 0.579 × 1.8 - 0.421 = +0.621 (유저 유리)
- 동점 패배 처리로 인한 약간의 하락 고려 필요
- NPC와의 대결 횟수 제한(남은 대결: X/3)으로 전체 노출 제한

## 3. 애니메이션 시퀀스

### 전체 타이밍 (비인터랙티브 — 자동 재생)

```
0.0s  "대결!" 클릭, 베팅 차감
0.3s  유저 주사위 2개 동시 등장 (card_fade_in 또는 pop_in)
0.5s  유저 숫자 빠르게 변경 시작 (shake + 랜덤 숫자)
      └ 0.15s 간격 × 8번 = 1.2s
1.7s  유저 주사위 확정, 합계 표시 (flash_up)
2.0s  NPC 주사위 2개 동시 등장 (card_fade_in)
2.2s  NPC 숫자 빠르게 변경 시작 (shake + 랜덤 숫자)
      └ 0.15s 간격 × 8번 = 1.2s
3.4s  NPC 주사위 확정, 합계 표시
3.7s  결과 팝업 (승리/패배)
4.2s  금액 표시 (+X원 / -X원)
      "닫기" 버튼으로 종료
```

### 동점 재굴림 시퀀스

```
3.7s  "동점! 재굴림!" 팝업 (0.5s)
4.2s  유저 주사위 재굴림 애니메이션 (0.5s 등장 + 1.2s 숫자변경)
5.9s  유저 확정, 합계 갱신
6.2s  NPC 주사위 재굴림 애니메이션
7.9s  NPC 확정, 합계 갱신
8.2s  결과 팝업 / 또다시 동점이면 재굴림 반복 (최대 3회)
```

### 재사용 UIAnim 메서드
- `pop_in(node)` — 패널 등장
- `card_fade_in(node)` — 주사위 등장 (블랙잭 카드 등장 재사용)
- `shake(node)` — 숫자 변경 시 흔들림
- `flash_up(node)` — 합계/결과 하이라이트
- `flash_down(node)` — 패배 시 하이라이트

### 숫자 변경 애니메이션 구현
- 주사위 Label.text를 0.15s 간격으로 1~6 랜덤 숫자로 갱신
- 동시에 shake(node) 적용하여 굴리는 느낌 연출
- 총 8번 반복 후 최종값으로 확정

```gdscript
    var rival_roll: int = _rng.randi_range(1, 6)
    # ...
```

### 신규 API

```gdscript
## 주사위 2개 굴림
func dice_roll() -> Dictionary:
    var d1: int = _rng.randi_range(1, 6)
    var d2: int = _rng.randi_range(1, 6)
    return {"d1": d1, "d2": d2, "total": d1 + d2}

## 결과 정산
func dice_settle(user_total: int, rival_total: int, bet: float) -> Dictionary:
    # user_total > rival_total → 승리, payout = bet * 1.8
    # user_total < rival_total → 패배, payout = 0
    # user_total == rival_total → 재굴림 또는 패배 (최대 3회 재굴림 후)
    return {"won": bool, "tie": bool, "payout": float, "rerolls_left": int}
```

### 변경 요약

| 항목 | 기존 | 신규 |
|------|------|------|
| 주사위 수 | 1개 | 2개 (합계 비교) |
| 동점 재굴림 | 최대 10회 | 최대 3회 |
| 배당 | 1.8배 | 1.8배 (유지) |
| API 형태 | `_play_dice(bet)` 일괄 | `dice_roll()` + `dice_settle()` 분리 |

## 7. 개발자 전달사항

### 수정 파일

| 파일 | 작업 |
|------|------|
| NPCManager.gd | `_play_dice(bet)` 삭제. `dice_roll()`, `dice_settle()` 신규 추가 |
| MainGame.gd | `_on_rival_challenge()`에 `dice` 분기 추가 (현재 default 토스트 경로). `_show_dice_game()` 신규. 주사위 애니메이션 시퀀스 구현 |
| UIAnim.gd | 기존 함수 재사용 (신규 함수 불필요) |

### 주요 구현 포인트

1. **UIAnim.gd 기존 함수 활용**
   - `pop_in(node)` — 패널 등장
   - `card_fade_in(node)` — 주사위 등장
   - `shake(node)` — 숫자 변경 시 진동
   - `flash_up(node)` / `flash_down(node)` — 합계/결과 표시

2. **주사위 숫자 변경 애니메이션**
   - Label.text를 0.15s 간격으로 랜덤 1~6으로 갱신
   - 갱신과 동시에 shake(node) 호출
   - `_rng.randi_range(1, 6)`으로 랜덤 숫자 생성
   - 총 8번 반복 후 최종 확정값 표시
   - Godot의 `await get_tree().create_timer(0.15).timeout` 사용

3. **MainGame.gd 분기 추가**
   - `_on_rival_challenge()`에서 NPC의 `game_type`이 `dice`인 경우 `_show_dice_game()` 호출
   - 현재는 default 경로로 토스트만 표시하는 상태
   - 블랙잭 분기(`bj`)와 동일 패턴으로 추가

4. **NPCManager API 분리**
   - 기존 `_play_dice(bet)`을 `dice_roll()` + `dice_settle()`로 분리
   - 이유: UI 애니메이션이 결과값을 필요로 하므로 굴림과 정산을 분리
   - `dice_roll()`은 MainGame에서 유저/NPC 각각 호출
   - `dice_settle()`은 애니메이션 완료 후 호출

5. **GDScript 함정 주의**
   - Dictionary get() + `:=`로 타입 추론하면 Variant 에러 → 명시적 타입 선언 사용
   - `float` 보다는 `int`로 합계 관리 (주사위 값은 정수)
   - `.0f` 미지원 → `str()` 또는 `round()` 사용

### 주요 흐름

1. `_show_dice_game()`: 오버레이 생성, 베팅 UI 표시
2. `_on_dice_start()`: 베팅 차감 → 유저 주사위 굴림 애니메이션 시작
3. `_animate_user_dice()`: 주사위 등장 → 숫자 변경(8번) → 확정, 합계 표시 → NPC 굴림 시작
4. `_animate_npc_dice()`: 동일 애니메이션 → 확정, 합계 표시 → 결과 비교
5. `_resolve_dice()`: 합계 비교 → 동점이면 재굴림(최대 3회), 아니면 결과 표시
6. `_show_dice_result()`: 결과 팝업 + 금액 + 기록 → "닫기" 버튼
