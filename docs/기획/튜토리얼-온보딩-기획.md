# 📖 StockTycoon 튜토리얼/온보딩 기획서

> **버전**: v1.0 | **작성일**: 2026-06-29
> **대상**: Phase 9 UI 개편 이후 신규 플레이어 가이드
> **원칙**: 방치형 게임이므로 수동 조작 최소화, 초보자가 3일 안에 핵심 루프를 이해하도록 설계

---

## 1. 개요

### 1-1. 목적

- 신규 플레이어가 **장전→장중→장마감** 페이즈 구조를 이해
- **매매 기본**, **정보력(에너지) 활용**, **데일리 브리핑 확인** 방법 습득
- 5개 탭 **[시장] [포트폴리오] [자산] [NPC] [진행]**의 각 역할 인지
- 첫 3일 동안 가이드 퀘스트를 통해 **게임의 재미 핵심(매매 수익)**을 체감

### 1-2. 설계 철학

| 원칙 | 설명 |
|------|------|
| **카이로소프트 감성** | NPC가 친근하게 설명, 텍스트 위주의 가벼운 온보딩 |
| **핸드헬딩 최소화** | Day 1은 강하게 가이드, Day 2~3은 점진적으로 자율 |
| **스킵 가능** | 언제든 튜토리얼 스킵 후 [진행] 탭에서 재시작 가능 |
| **보상 동기 부여** | 가이드 퀘스트 완료 시 현금/에너지 보상으로 계속 진행 유도 |

## 2. 튜토리얼 흐름 (Day 1~3)

### 2-1. 전체 타임라인

```
[게임 시작]
  └─ Day 1: 장전 — 웰컴 브리핑 + 시장 둘러보기 + 첫 매수
  └─ Day 1: 장중 — 주가 관찰 + 첫 매도 (초보 보호 설명)
  └─ Day 1: 장마감 — NPC 탭 소개 + 데일리 정산 확인
  └─ Day 2: 장전 — 데일리 브리핑 활용법 + 정보력(에너지) 설명
  └─ Day 2: 장중 — 포트폴리오/자산 탭 활용 + 2번째 거래
  └─ Day 2: 장마감 — 자동매매 슬롯 개념 소개
  └─ Day 3: 장전 — 뉴스 이벤트 확인 (정보력 소모 체험)
  └─ Day 3: 장중 — 자율 플레이 (힌트만 제공)
  └─ Day 3: 장마감 — 온보딩 완료 축하 + 진행 탭 안내
```

### 3-3. 하이라이트 노드 구현 (GDScript 스펙)

```gdscript
## TutorialHighlight.tscn — 하이라이트 오버레이
## TutoriaManager가 하이라이트 대상을 지정하면 해당 노드를 감싸는 테두리 표시

extends CanvasLayer

signal highlight_dismissed()

@onready var dim_overlay: ColorRect = $DimOverlay
@onready var highlight_rect: NinePatchRect = $HighlightRect
@onready var tooltip: PanelContainer = $Tooltip
@onready var tooltip_label: RichTextLabel = $Tooltip/Margin/VBox/Label

var _target: Control = null
var _tutorial_id: String = ""

func show_highlight(target: Control, title: String, body: String, tutorial_id: String) -> void:
    _target = target
    _tutorial_id = tutorial_id
    _update_rect_position()
    tooltip_label.text = "[b]%s[/b]\n%s" % [title, body]
    dim_overlay.visible = true
    highlight_rect.visible = true
    tooltip.visible = true
    # 페이즈 진행 중일 때 하이라이트가 대상을 따라갈 수 있도록
    _target.resized.connect(_update_rect_position)

func _update_rect_position() -> void:
    if not _target:
        return
    var global_pos: Vector2 = _target.global_position
    var size: Vector2 = _target.size
    highlight_rect.global_position = global_pos - Vector2(2, 2)
    highlight_rect.size = size + Vector2(4, 4)

func dismiss() -> void:
    dim_overlay.visible = false
    highlight_rect.visible = false
    tooltip.visible = false
    if _target and _target.resized.is_connected(_update_rect_position):
        _target.resized.disconnect(_update_rect_position)
    highlight_dismissed.emit()
```

## 4. TutorialManager 설계

### 4-1. 오토로드 추가

| 항목 | 내용 |
|------|------|
| **싱글톤명** | `TutorialManager` |
| **스크립트** | `scripts/autoload/TutorialManager.gd` |
| **데이터** | `data/tutorial_steps.json` (스텝 정의) |

### 4-2. 핵심 상태 변수

```gdscript
## TutorialManager.gd

signal step_started(step_id: String)
signal step_completed(step_id: String)
signal tutorial_finished()

var _steps: Array = []              # tutorial_steps.json에서 로드
var _current_step_idx: int = -1
var _tutorial_completed: bool = false
var _skipped: bool = false
var _pending_step_id: String = ""

# 저장/로드용
var completed_steps: Dictionary = {}  # step_id -> day_completed
```

### 4-3. 스텝 트리거 로직

```gdscript
func check_triggers() -> void:
    if _tutorial_completed or _skipped:
        return

    var day: int = GameManager.player.get("day", 1)
    var phase: int = GameClockManager.current_phase

    for i in range(_current_step_idx + 1, _steps.size()):
        var step: Dictionary = _steps[i]
        var sid: String = step.get("id", "")

        # 이미 완료된 스텝 스킵
        if completed_steps.has(sid):
            continue

        # 조건 검사
        if _check_conditions(step, day, phase):
            _current_step_idx = i
            _show_step(step)
            return
```

### 4-4. 스텝 조건 검사

```gdscript
func _check_conditions(step: Dictionary, day: int, phase: int) -> bool:
    var conds: Dictionary = step.get("conditions", {})

    # day 조건
    if conds.has("min_day") and day < int(conds["min_day"]):
        return false
    if conds.has("max_day") and day > int(conds["max_day"]):
        return false

    # phase 조건 (0=장전, 1=장중, 2=장마감)
    if conds.has("phase"):
        if phase != int(conds["phase"]):
            return false

    # player action 조건
    if conds.has("first_buy_done") and conds["first_buy_done"]:
        if GameManager.player.get("trade_count", 0) < 1:
            return false
    if conds.has("news_read") and conds["news_read"]:
        if QuestManager._daily_news_checks < 1:
            return false

    # 선행 스텝 조건
    if conds.has("requires_step"):
        var req: String = conds["requires_step"]
        if not completed_steps.has(req):
            return false

    return true
```

### 5-2. QuestManager 확장 명세

```gdscript
## QuestManager.gd에 추가할 변수/함수

# 기존 변수에 추가
var _onboarding_defs: Array = []
var _onboarding_progress: Dictionary = {}  # quest_id -> {progress, claimed}

# _load_data()에 추가
var odata = _load_json("res://data/tutorial_quests.json")
if odata:
    _onboarding_defs = odata.get("onboarding_quests", [])
for q in _onboarding_defs:
    _onboarding_progress[q["id"]] = {"progress": 0, "claimed": false}

# TutorialManager 연동용
func complete_onboarding_quest(quest_id: String) -> void:
    if _onboarding_progress.has(quest_id):
        var entry = _onboarding_progress[quest_id]
        if not entry.get("claimed", false):
            entry["progress"] = 1
            entry["claimed"] = true
            _onboarding_progress[quest_id] = entry
            # 해당 퀘스트 정의 찾아서 보상 지급
            for q in _onboarding_defs:
                if q["id"] == quest_id:
                    _grant_quest_reward(q)
                    break

# 진행도 업데이트: trade_count, news_check 타입은 기존 _update_quest_progress에서도 처리
# → _update_quest_progress()에 onboarding loop 추가:
for q in _onboarding_defs:
    if q.get("type") == type and not _onboarding_progress[q["id"]].get("claimed", false):
        _set_progress(_onboarding_progress, q["id"], int(daily_val), int(q.get("target", 1)))
```

## 8. 저장/로드 연동

### 8-1. TutorialManager serialize/deserialize

```gdscript
func serialize() -> Dictionary:
    return {
        "tutorial_completed": _tutorial_completed,
        "skipped": _skipped,
        "completed_steps": completed_steps.duplicate(),
        "current_step_idx": _current_step_idx
    }

func deserialize(data: Dictionary) -> void:
    _tutorial_completed = data.get("tutorial_completed", false)
    _skipped = data.get("skipped", false)
    completed_steps = data.get("completed_steps", {}).duplicate()
    _current_step_idx = int(data.get("current_step_idx", -1))
```

### 8-2. SaveManager 연동

SaveManager의 `save_game()` / `load_game()`에 TutorialManager 추가:
```gdscript
# save_game()에 추가
save_data["tutorial"] = TutorialManager.serialize()

# load_game()에 추가
TutorialManager.deserialize(data.get("tutorial", {}))
```

## 11. 구현 시 주의사항

### ⚠️ 반드시 지켜야 할 사항

1. **GameClockManager._process 블킹 금지**
   - TutorialManager가 화면을 일시정지하더라도 `_process`는 계속 실행되어야 함
   - `is_paused`는 NPC 대화용으로만 사용, 튜토리얼은 별도 `is_tutorial_paused` 플래그 고려
   - 튜토리얼 풍선이 열려 있을 때는 **시간 진행을 멈추지 않음** (방치형 성격 유지)
   - 단, `action: click_target`인 경우에만 대상 클릭까지 대기

2. **QuestManager와의 중복 추적 방지**
   - `on_trade_made()`가 양쪽에서 호출되지 않도록 TutorialManager → QuestManager 단방향 연동
   - 온보딩 퀘스트 완료는 TutorialManager에서 `complete_onboarding_quest()`로만 처리

3. **저장 데이터 호환성**
   - 기존 세이브 데이터에 `tutorial` 키가 없을 수 있음 → `deserialize`에서 기본값 처리 필수
   - `tutorial_completed: false` (기존 세이브) → 기존 유저에게는 튜토리얼 표시 안 함
   - **기존 유저 옵션**: `player.day > 3`이면 튜토리얼 자동 스킵

4. **MainGame.gd 파편화 주의**
   - MainGame.gd는 4,695줄로 이미 큼
   - TutorialManager는 완전히 독립 싱글톤으로 구현
   - 하이라이트/풍선 UI는 별도 씬으로 분리
   - MainGame.gd에는 시그널 연결 코드만 최소 추가

5. **폰트/디자인 일관성**
   - 모든 튜토리얼 UI에 NeoDungGeunMo 사용
   - 배경 `#1E1E2E`, 패널 `#2A2A3D`, 골드 `#FFD54F`, 상승 `#66BB6A`, 하락 `#FF7043`
   - 절대 AI 느낌 텍스트 금지 — NPC가 말하는 자연스러운 톤

6. **한국어 숫자 단위**
   - 모든 금액 표기: 만/억/조 단위 (예: "50만원", "200만원", "2,000만원")
   - K/M 축약 절대 금지

7. **모바일 대응**
   - 풍선 터치 영역 충분히 크게 (최소 48x48dp)
   - 하이라이트가 작은 버튼을 가리지 않도록 위치 조정
   - 풍선이 화면 하단에 고정되는 것이 모바일에서 더 안정적

8. **StoryManager와의 관계**
   - StoryManager의 ch1은 게임 시작 시 자동 재생 (check_start_story)
   - TutorialManager는 StoryManager와 **독립적으로** 동작
   - 동시에 표시될 수 있으나, 스토리 컷신이 재생 중이면 튜토리얼 대기
   - `StoryManager.is_playing() == true`이면 TutorialManager.check_triggers() 스킵
